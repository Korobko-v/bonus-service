Этап 1:
    Создана структура проектов, реализован REST-сервис в соответствии с задачей
        1) Начислить бонусы по карте клиента
        2) Списать бонусы по карте клиента
        3) Возврат списанных/начисленных бонусов (этот кейс будет срабатывать,
            например, при возврате товара)
        4) Получить баланс по номеру карты
        5) Получить историю операций по номеру карты
    Для реализации задачи была выбрана база PostgreSQL

Этап 2:
    Реализованы миграции (Liquibase). На данном этапе добавлены миграции для таблиц bonus_cards и bonus_transactions.

Этап 3:
    Подключён модуль Spring Security. Реализована аутентификация и авторизация (запросы на чтение - права у всех, 
    на модификацию - только админ). Также добавлено разделение на получение личных данных (для любого пользователя) 
    и любых по номеру карты (админ). Добавлена валидация и кастомные исключения. 
Этап 4:
    Оптимизация SQL-запросов. В тестовую базу загружены 100000 карт и 1000000 транзакций для анализа производительности.
